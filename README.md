# Alan Betty - Portfolio

hey, I'm Alan. frontend dev + UI/UX designer from Kerala, India 🇮🇳. also built a whole browser ([Pyraxis](https://pyraxisbrowser.tech)).

no templates, no UI libraries, no CSS frameworks. all hand built, took way too long ngl.

## Run it

```bash
npm install
npm run dev
```

opens on http://localhost:3000. `npm run build` for prod.

## Stack

Next.js 15, React 19, TypeScript, Three.js, Lenis, GSAP and plain CSS.

## The black hole

the background is a real ray traced black hole, not a video. every pixel bends light using the actual physics equation:

```
d²r/dλ² = -3·h²·r / |r|⁵        h = |r × v|
```

( dw i didnt know any of this before i reasearched abt this. AI Did the complex part.)

so the shadow, photon ring and warped stars all just show up on their own. there's also 900 stars falling in and getting eaten, and the hole slowly follows your cursor. lowkey my fav part fr.
